# 复兴 · 动画工作室

## 打开编辑器
在 Web 项目目录运行 `npm run dev`，然后打开终端显示的本地地址，加上 `/mods/revival/qa/authoring-preview.html`。
这是开发工具页面，使用现有的 Vite QA 入口；不是直接双击 HTML，也不自动作为正式游戏菜单安装。

## 第一次使用：三步即可
1. 打开后已有彩色入门人偶和待机、行走动作。点「播放」观察，再暂停。
2. 左侧选部位，时间轴选时间，拖关节移动；点「旋转」后拖绿色圆环。默认自动记录姿势，也可在右侧输入数值，按 Enter 确认。
3. 播放检查，点「保存工程」，下载 JSON。确认文件保存后再点「我已保存文件」。下次通过「打开工程」继续。

## 用自己的素材做动作
- 已有部位：点对应图片插槽，在右侧「图片」导入 PNG/JPG/WebP。支持透明 PNG；单张不超过 8 MB、4096×4096。
- 新部位：先选父部位 →「＋ 子部位」→「图片插槽 ＋ 添加」，再导入图片。名称、缩放、父子关系等在高级设置里。
- 图片偏移用于把素材对准关节；层级越大越靠前。初始配置和图片关键帧不同，已有关键帧可以覆盖初始配置。
- 「＋ 新动作」创建动作；展开动作设置可改名、复制、调整时长和帧率。
- 时间轴拖动菱形改变时间。移到已有姿势点上会替换该点；事件允许同一时间有多个。可撤销。
- 关闭「自动记录姿势」后，只能修改已有姿势点；新时间需要先点「记录当前姿势」。
- 「事件」可以添加脚步、命中等时刻标记，参数是 JSON。标记不会自行播放音效或造成伤害。

## 保存、草稿与兼容范围
- **保存工程**包含骨骼、图片和全部动作；导入的图片嵌入 JSON，无需携带原图片文件即可继续编辑。
- **本机草稿**使用独立的浏览器 IndexedDB，不碰游戏存档。修改后自动备份，可在左侧「新建、原版与草稿 → 兼容原版 / 草稿」手动恢复。它不是已下载文件，清理浏览器数据会丢失。
- **仅导出当前动作工程**仍包含完整骨骼和附件，但只带一个动作；不表示其余动作已保存。
- **原版兼容工程**显示骨架参考，不在此页重建原版逐帧部件外观。游戏的原有动画兼容路径不变。
- **原版兼容补丁**需从「打开原版兼容工程」开始，选择 idle/walk/shoot/hit/death 的 0–7 标准动作。导出姿势、插槽轨道，以及你确实改过的时长／帧率／循环／播放时长／事件；未改动的节奏不会写进补丁，因此原样导出仍复现原版。补丁沿用已有导入工具；完整工程不是可直接安装的游戏 MOD 包。
- 预览方向只使用已有插槽方向配置，不自动生成四向美术。入门人偶是几何示例，不是已完成的新僵尸单位。
- 新图片、新动作与命中事件要投入游戏，仍需配置素材注册、单位动作映射及运行时逻辑；此编辑器不自动改写游戏数据。

## 常用操作
空格：播放/暂停；V：移动；R：旋转；F：适应画布；左右箭头：前后帧；右键拖动：平移；滚轮：缩放。
Ctrl+Z：撤销；Ctrl+Y / Ctrl+Shift+Z：重做；Ctrl+C/V：复制/粘贴姿势；Ctrl+S：生成工程文件；Delete：删除选中的关键帧；Esc：取消正在进行的拖动。
输入框内优先输入文字，不触发上述编辑快捷键。

## 最小检查
在 Web 目录运行：

```sh
node public/mods/revival/tools/authoring_editor_regression.mjs

npm run build
```

## 四向僵尸工程（2026-09-14）

点击左侧 **打开四向僵尸工程**。未保存修改会先提示，切换可以撤销。完整工程位于 `data/examples/zombie-project.json`（相对复兴目录；也可用「打开工程」导入）。保存时图片和署名一起嵌入 JSON，不依赖外部图片地址。

- 24 个动作：待机、行走、攻击、啃咬、受击、死亡 × 东南、西南、西北、东北。
- 「预览方向」会切换当前动作对应的朝向；每个朝向是真实源图，不靠镜像冒充。
- 待机 / 行走循环；攻击 / 啃咬 / 受击恢复站立；死亡播放一次并保持尸体末帧。
- 「图片」页和时间轴紫色点用于切换图片、调整帧时间。整体根节点可叠加平移 / 旋转关键帧，但源图**没有分层肢体**，不能独立弯胳膊。
- 行走为原地步态循环，世界位移由未来的单位控制逻辑处理。脚步、攻击、啃咬、受击、倒地事件只是标记，不会播放音效或结算伤害。
- 署名许可见 assets/zombie/LICENSE.md。保留原图分辨率，仅裁掉透明边缘并修正偏移，脚底注册点不变；没有重绘或降低画布分辨率。
- 工程没有自动接入战斗或遭遇生成。所有本次变更限于复兴 DLC 的素材、编辑器、示例及测试。
- 可重建示例：在 Web 目录运行 `node public/mods/revival/tools/build_zombie_project.mjs`。这个命令会覆盖捆绑示例；自己的修改请另存文件。
