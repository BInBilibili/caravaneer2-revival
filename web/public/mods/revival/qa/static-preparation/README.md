4. 接入四方向动作轨迹、静态皮肤选择、原版染色、枪口挂点和独立阴影。
5. 验证全部人物外观/装备组合，不仅是静止帧；同时核验原版攻击、脚步和死亡事件时点。
6. 通过外观、帧耗时与内存验收后，再替换 DLC 默认人物渲染路径。

上述内容不能由单纯固定原帧号、缩放裁剪边界或者复制骨骼测试动作代替。
原版没有骨骼关键帧并不意味着不能重制，而是无法无损自动反解成一套已经完成的角色骨架。
